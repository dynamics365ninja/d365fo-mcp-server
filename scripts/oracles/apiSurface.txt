# The API surface the coverage plan intends to document, as a committed list.
#
# Regenerate the snapshot on a VM after a platform update:
#   npm run oracle:members -- --from-file scripts/oracles/apiSurface.txt \
#     --names-only --json eval/api-members.snapshot.json
#
# WHY A LIST AND NOT A COMMAND LINE. Every knowledge defect this repo has shipped
# of the "names an API that does not exist" class was written from memory
# (`SysRunnable::run()`, `assertExpectedException`, `initArgs()` on a report
# controller). A committed list makes the question reviewable and lets the same
# question be re-asked after a platform update, which is when an answer silently
# changes.
#
# A NOT-FOUND HERE IS AN ANSWER, NOT A FAILURE. Kernel-implemented types have no
# AOT XML anywhere by construction (xRecord, FormRun, FormDataSource, the
# DataEntity runtime contexts), so "not found" is how the snapshot records
# "kernel — the metadata index cannot answer about it, use a compiler probe and
# add an allow-list entry". Those are grouped last, and they are expected to be
# absent.
#
# Lines are trimmed; `#` starts a comment.
